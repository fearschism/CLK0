Handling these files

Returns are held in this browser only and are never uploaded anywhere by this page. They are classified : use a managed device, and clear the data when you have finished with it.

How the rating is produced

Organisations answer plain questions in English and Arabic — mostly Yes / No / Not sure, a choice from a list, or a set of tick boxes. They are never shown a score. Each answer carries a value from 0 to 5 that only this console applies, so returns stay easy to complete but still comparable.

From answers to a rating

  1. Each answer becomes a value out of 5. Yes scores 5, No scores 0, and Not sure scores 1 — if the accountable respondent cannot confirm a capability, it is not being managed. Answers picked from a list carry the value shown below. For tick-box questions the value is the share of items ticked.
  2. Each section is a weighted average of its questions. Core questions count 1.5 times a standard one.
  3. The overall rating is a weighted average of the sections, using the section weights shown on the dashboard. Questions marked Not applicable are left out of both the top and the bottom of the average, rather than counted as zero.
  4. Anything below the target rating becomes an action, ranked by section weight × question weight × the size of the gap. The top band is Priority 1.

Two things to remember when you report this

Returns are self-declared: the rating reflects what organisations tell you, not audited evidence. And a low answered percentage or a high Not sure count matters as much as a low rating — it usually means nobody has visibility, which is itself the finding.
